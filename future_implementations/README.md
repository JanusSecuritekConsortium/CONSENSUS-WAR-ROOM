# Future Implementations

This folder preserves related prototypes and integration candidates for later
Consensus War Room work.

## Riko Project

`riko_project/` contains a voice companion pipeline that combines ASR, an LLM
conversation loop, and GPT-SoVITS speech synthesis. The imported source was
sanitized to read the OpenAI key from an environment variable. The original
sample WAV from the zip is intentionally not tracked by Git.

## Flet Server Prototype

`flet_server_prototype/` contains a standalone Flet-based Consensus UI prototype
with theme assets and simple proposal/verdict file connectors.
